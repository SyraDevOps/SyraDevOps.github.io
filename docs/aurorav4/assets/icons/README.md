# Ícones do Aurora

Esta pasta está reservada para a identidade visual futura. Quando a logo estiver pronta, exporte:

- `icon-192.png` — 192 × 192 px
- `icon-512.png` — 512 × 512 px
- `icon-maskable-512.png` — 512 × 512 px com margem segura
- `apple-touch-icon.png` — 180 × 180 px

Depois, inclua os arquivos no campo `icons` de `manifest.webmanifest` e adicione o `apple-touch-icon` ao `index.html`.
